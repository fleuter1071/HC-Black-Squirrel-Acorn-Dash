# Haverford Brand Notes

Reference notes for future visual design work in this project.

Reference URL: https://www.haverford.edu/marketing-and-communications/graphic-identity

## Core Colors

### Haverford Red

- Pantone: 201
- CMYK: 7 / 100 / 65 / 32
- RGB: 152 / 30 / 50
- Hex: `#8B0000`

### Squirrel Black

- Pantone: Black
- CMYK: 40 / 40 / 40 / 100
- RGB: 0 / 0 / 0
- Hex: `#000000`

## Extended Palette Notes

The preferred logo and wordmark core colors are black and dark red, Pantone 201.

An extended palette is also available. These additional colors are derived from Founders Hall and the natural surroundings of the Haverford campus. Future visual updates should consult the Graphic Identity Standards and Guidelines manual when exact extended-palette values are needed.

## Typography

### Serif Font

Georgia is the preferred serif font for general, everyday use.

Recommended uses:

- PowerPoint presentations
- Keynote presentations
- Letters
- Fax cover sheets

Available styles:

- Regular
- Italic
- Two weights

### Sans Serif Font

Verdana is the preferred sans serif font for general, everyday use.

Recommended uses:

- Name tags
- Email signatures
- Signage
- Small text in PowerPoint presentations
- Small text in Keynote presentations

Available styles:

- Regular
- Italic
- Two weights

### Web Font

Lato is the preferred sans serif font for the College website.

In special cases approved by Marketing and Communications, Lato can be used when Avenir, the preferred sans serif font, is not an option.

Available styles:

- Regular
- Italic
- Variety of weights

## Project Usage Notes

- Use Haverford Red for official-feeling accents, cape treatments, badges, and high-emphasis UI moments.
- Use Squirrel Black for SBS identity, strong outlines, and squirrel-specific iconography.
- Use Georgia when a design moment should feel institutional, alumni-facing, or Haverford-formal.
- Use Verdana or Lato when readability at small sizes matters most.
- Current game typography may remain stylized for playfulness, but future brand-aligned screens should consider these standards.
